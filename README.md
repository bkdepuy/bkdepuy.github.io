---

## About this site

This site serves two connected purposes:

**The Medium** is a foundational framework in physics and philosophy built from first principles — asking what must be true of whatever underlies physical reality before space, time, particles, and observers are assumed. It posits two primitives (distinction and relation) and treats space, time, geometry, and quantum behavior as emergent rather than fundamental. Published on Zenodo (concept DOI: [10.5281/zenodo.18927154](https://zenodo.org/records/18927154)).

**Renewal** is a broader stream of writing drawn from seventy-nine years of naturalist practice, deliberate habitat stewardship, and a life organized around experiences rather than material gains. The renewal message and the physics framework are expressions of the same underlying conviction: the universe is irreducibly active, and attention is the appropriate response.

## Adding new posts

Each new post is a standalone HTML file following the same template as `blog_biography.html`. Steps:

1. Copy `blog_biography.html` to a new file (e.g. `crow_family.html`)
2. Update the title, breadcrumb, dateline, and article content
3. Add the new post to the list in `renewal.html` (or `medium.html` for framework writing)
4. Add it to the recent writing list in `index.html`
5. Upload to this repository — GitHub Pages publishes automatically within minutes
